# 測試紀錄

用 Playwright 在瀏覽器實際操作遊戲（`tests/e2e.cjs`）：真的點按鈕、按鍵盤、拖曳搖桿、重新整理頁面，再讀取瀏覽器裡的進度確認結果。

## v4.1 修正：音樂重疊、手機移動太慢｜2026-11-12

**共 91 項全部通過**（原本 87 項加上本次 4 項）。

| 問題 | 原因 | 修正 | 測試 |
|---|---|---|---|
| 音樂會重疊 | iPhone、iPad 的 Safari 不允許程式調整 `<audio>` 的音量（永遠是 1），淡出永遠到不了 0，舊曲子不會暫停；瀏覽器擋自動播放時的重試也可能叫回舊區域的曲子 | 音量改用 Web Audio 的 GainNode 控制；淡出結束後一定暫停舊曲子；重試時用最新的區域 | 模擬 iPhone 不能改音量，連續換區五次後只有一首在播；靜音與降低音量仍有效（通過） |
| 手機移動太慢 | 虛擬搖桿要推到最邊緣才是全速；每幀移動量上限 0.05 秒，畫面更新慢時角色走得比設定慢 | 搖桿加上速度曲線（中間一小段不動，推到約一半就是全速）；每幀上限放寬到 0.1 秒 | 搖桿推一半的速度（2.84 單位／秒）接近鍵盤全速（2.95）（通過） |

## 如何重跑

```bash
python -m http.server 8000                 # 另一個終端機
BASE=http://localhost:8000 node tests/e2e.cjs
```

測試會清除測試用瀏覽器裡的遊戲進度（不會動到你平常的瀏覽器）。無法連到 jsDelivr 時，加上 `THREE_DIR=<three@0.170.0 套件資料夾>`。
