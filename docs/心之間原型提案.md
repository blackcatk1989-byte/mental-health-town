## 1. 定位

「心之間」是面向台灣成年大眾的日常探索解謎網頁遊戲原型。玩家是剛搬到「微光里」的居民，在 3D 小鎮（或文字模式）裡走動、和人聊天、親手完成小練習與謎題，收集「理解卡」，並在適合的時候使用它們。

核心目的：

1. 心理科普：從角色的日常理解心理困擾與個別差異。
2. 同理與自我理解：觀察想法、感受與處境，不提供自我診斷。
3. 體驗心理練習：把與心理治療相關的入門概念，做成親手操作的小練習與謎題。
4. 連結現實支持：提供實體諮商、醫療、政府協助及民間支持的查詢入口。

| 項目 | 內容 |
|---|---|
| 主要對象 | 台灣一般成年大眾；無須心理學背景 |
| 形式 | 可在瀏覽器遊玩的 3D 探索解謎原型；另有文字模式 |
| 場景 | 微光里：小廣場、咖啡店外、小花園，同一張小地圖 |
| 視角 | 第三人稱固定斜俯視，只平滑跟隨 |
| 規模 | 一個場景、兩位可對話角色、一段完整主線、兩個練習、兩個謎題、六張理解卡、一隻提示用的貓 |
| 語言 | 繁體中文，台灣日常口語 |

## 2. 核心循環與體驗原則

探索微光里 → 和人聊聊 → **親手做**練習或謎題 → 取得理解卡 → 在情境中使用卡片 → 角色自己做出小決定 → 繼續探索。

全程約 20 分鐘。不計時、不扣分，隨時可以停下來；卡住時可以找麻糬。

### 2.1 心理健康內容的界線（不變）

- 不以「憂鬱區」「焦慮角色」等方式為地圖與人物命名、配色或分類；名牌旁不加疾病標籤。
- 不依對話、遊戲表現或收藏結果，輸出疾病名稱、罹病機率、心理類型或風險判定；不設心理分數、治癒率、治癒結局。
- 單一經驗不代表所有人；相似感受不能用來推定診斷。
- 不用「你想太多」「只要正向就好」作為教學結論；常見誤解以補充說明引導，不羞辱玩家。
- 結局不寫成「原來都是誤會」或問題完全解決。
- 不要求玩家輸入私人經歷；練習與謎題都使用預寫的虛構情境。
- 所有新文案標示「內容草案，尚未完成專業審閱」。

## 3. 世界、角色與主線

### 3.1 微光里

| 區域 | 配置與用途 |
|---|---|
| 小廣場 | 玩家起點、里辦公處的公布欄（含找支持海報） |
| 咖啡店外 | 曉晴、她的便條（想法放大鏡）、還沒收的三張桌子與收桌托盤（謎題 E02） |
| 小花園 | 阿德、風鈴、長椅、植物角落的木架與三盆植物（謎題 E01） |

咖啡店內部不開放。

### 3.2 角色

**曉晴｜咖啡店店員**
- 喜歡畫明信片、研究咖啡。在群組約週末聚餐，朋友小月已讀沒回，她開始想「是不是我太煩了」。
- 可在一段可跳過、可拒絕繼續聽的對話中，主動提到曾被診斷有憂鬱症、正在接受專業協助。這段不提供額外獎勵、不影響任務。
- 先以姓名、生活與興趣被認識。

**阿德｜接案工作者、花園志工**
- 平常接設計案，下班後到社區花園澆水。下班後還一直看手機，反覆猜客戶筱玉姐那句「再看看」是什麼意思。
- 不設定診斷，也不由玩家或旁白推論。能表達自己的需要，也會主動提出練習。

**只出現在訊息與對話中（不是可對話角色）**：小月（曉晴的朋友）、筱玉姐（阿德的客戶）。

**橘貓麻糬**：里內的橘貓，不能對話，只會動作。負責提示（見第 5 節）。

玩家是剛搬來的居民，使用預設中性造型，不填真名、性別或健康資訊，也不是心理師或拯救者。

### 3.3 主線《今天有點卡卡的》

| 步驟 | 玩家行動 | 卡片與重點 |
|---|---|---|
| 1. 公布欄 | 看公布欄，得知找支持隨時可開 | — |
| 2. 認識曉晴 | 曉晴一直看手機。選「給建議」會被她客氣帶過，**先問她想不想聊**，她才說出小月已讀沒回的事 | 取得 **K01「先問，再陪伴」**；不需要聽確診經驗 |
| 3. 想法放大鏡 | 看曉晴的便條，**親手**完成練習（第 4.1 節） | 取得 **K02「想法不等於事實」** |
| 4. 【用卡點】對曉晴用 K02 | 聊「要不要直接問問看」；玩家提供觀點，**由她自己決定**（傳一句「不急喔，有空再回我～」或先不傳） | 記錄她的決定 |
| 5. 【用卡點】對阿德用 K01 | 問「你現在需要什麼？」；阿德說想先停一下，提出練習 | — |
| 6. 回到這座花園 | **親手**完成練習（第 4.2 節） | 取得 **K03「回到此刻」** |
| 7. 【用卡點】在長椅用 K03 | 陪阿德決定今晚的一小步：手機收起來明天再回／先回一句「收到」／先坐十分鐘；由他自己選 | 記錄他的決定 |
| 8. 收尾 | 聽兩人各自的小決定 | 取得 **K04「求助不必獨自承擔」** |

收尾：小月還沒回，筱玉姐的意思也還不清楚。兩人各自做了一個今天做得到的小決定——「目前還不知道，也可以先這樣」。

對話使用預寫分支，台灣日常口語、短句，像朋友聊天，不用教科書語氣。

## 4. 親手做的練習與謎題

### 4.1 練習：想法放大鏡（取得 K02）

位置：咖啡店外的桌上。約 3 分鐘。

1. 讀曉晴的便條：「週末聚餐的訊息傳出去了。小月已讀，兩個小時都沒回。她一定覺得我很煩。我是不是不該約？心裡悶悶的。」
2. 用放大鏡把每一句放進「■ 我確定知道的事」「？ 我的猜測」「♡ 我的感受」。**猜測放不進「確定知道的事」**，只提示方向（例如「這句是小月說的，還是曉晴腦中想的？」）。
3. 為「我太煩了」想想其他可能（至少選一個，沒有標準答案）。
4. 結果卡：確定的事、猜測、感受、其他可能，以及「**目前還不知道**」。
5. 完成後顯示摘要並取得 K02。

體現的概念：親手把事實和解讀分開，看見猜測只是可能之一。這是入門練習，不是完整的認知行為治療。概念參考 [NIMH 心理治療介紹](https://www.nimh.nih.gov/health/topics/psychotherapies)。

### 4.2 練習：回到這座花園（取得 K03）

位置：小花園。約 2～3 分鐘，沒有強制等待。

三輪「看、聽、摸」：每輪選一樣留意的東西，接著阿德的念頭冒出來（例如「筱玉姐說『再看看』，是不是不滿意？」）。玩家**不需要趕走念頭**，按「看見了，回到花園」再繼續。最後有可選的離開螢幕提示，完成後顯示摘要並取得 K03。

- 「先停在這裡」隨時可以離開；中途離開不取得卡片，下次可以再來。
- 聲音那一輪：音效開啟時可播放自製風鈴聲；關閉時用文字描述，不依賴聲音。
- 不閉眼、不憋氣、不考驗呼吸速度、不偵測情緒，也不把點選稱為完整的心理治療。

體現的概念：念頭冒出來很正常，看見它、把注意力帶回來就是在練習。概念參考 [WHO 壓力調適指南](https://www.who.int/thailand/activities/doing-what-matters-in-times-of-stress)。

### 4.3 謎題 E01：三盆植物（取得「每個人需要的空間不同」）

位置：小花園角落的木架。入口是木架前的三盆植物、澆水壺和阿德的紙條。

玩家依線索把迷迭香、薄荷、腎蕨放到木架的「☀ 向陽」「◐ 半陰」「● 遮蔭」。每盆植物都有三種線索：

| 植物 | 葉子 | 土 | 標籤 | 答案 |
|---|---|---|---|---|
| 迷迭香 | 細細硬硬，像小針 | 很乾、鬆鬆的 | 愛曬太陽，土乾了再澆 | 向陽 |
| 薄荷 | 軟軟的、有點下垂 | 微微濕潤 | 早上有太陽就好，下午怕曬 | 半陰 |
| 腎蕨 | 葉尖有點焦 | 很濕、涼涼的 | 怕直射陽光，喜歡潮濕 | 遮蔭 |

完成後的說明：**需要不同，沒有哪個比較好。** 取得卡片後，可以和曉晴、阿德聊各自喜歡的相處方式（取代 v3 的安靜座位分支）。

### 4.4 謎題 E02：還沒收的三張桌子（取得「感受不是診斷」）

位置：咖啡店外。入口是收桌托盤上曉晴的筆記：「這三桌的客人，離開前都嘆了一口氣、揉了揉眼睛。」

玩家從桌上的物品，配對三位客人嘆氣的原因：

| 桌子 | 留下的東西 | 原因 |
|---|---|---|
| 靠窗那桌 | 畫滿螢光筆的講義、三個空咖啡杯、便利貼「明天 9:00 第二節」 | 明天要考試，熬夜念書很累 |
| 中間那桌 | 摺起來的帳單、寫滿加減的餐巾紙、租屋廣告傳單 | 這個月的房租還沒湊齊 |
| 門口那桌 | 寫一半的明信片、國外郵票、兩人合照 | 想念住在遠方的好朋友 |

完成後的說明：**相似的表現，背後的處境不同。** 只看表面，沒辦法知道一個人怎麼了，更不能替人下診斷。取得卡片後，可以和兩人聊「不要急著替彼此下結論」。

### 4.5 謎題共通規則

- 不計時、不扣分、可無限重試；中途離開會保留已擺的位置，回來繼續。
- 線索都在同一區域，不需要遊戲外的知識；每題約 1～2 分鐘。
- 答錯只指出「哪一項再看看、看哪個線索」，不說答案、不評價玩家。
- 不依賴聲音或顏色作為唯一線索：每條線索都有文字；位置同時有圖形（☀◐●）和文字；3D 的三盆植物形狀也不同。
- 入口融入場景，要留意才會發現，但不藏在看不到或走不到的地方。
- 文字模式提供相同的謎題，與 3D 共用存檔。
- 找支持面板、非診斷說明、主線必要卡永遠不被謎題擋住；完全不解謎也能完成主線。

## 5. 提示系統：橘貓麻糬

- 麻糬跟在玩家附近。玩家卡住時和牠互動（3D 靠近按 E 或點牠；文字模式按「問問麻糬」）。
- 先選要問什麼：「目前的目標」或還沒解開的謎題。
- 提示分三層，**由玩家決定要看到哪一層**：
  1. 麻糬往線索所在的區域走去
  2. 麻糬停在線索物件旁
  3. 直接標出互動位置（3D 顯示光柱；文字模式在該項目標示「就是這裡」）
- 目標完成（例如謎題解開）後，標記自動收起；全部完成時麻糬只會打呵欠。
- 取代 v3 卡冊的「顯示位置」按鈕；卡冊仍保留文字線索。

## 6. 理解卡

六張卡的知識重點不變。卡冊依「理解感受、觀察想法、陪伴與求助」整理，不按疾病分類，沒有稀有度、攻擊力或分數。用卡後卡片保留，不消耗、不交易。

| 卡 | 知識重點 | 取得方式 | 使用 |
|---|---|---|---|
| K01 先問，再陪伴 | 先詢問需要，尊重對方的選擇與界線 | 和曉晴初次對話時，先問她想不想聊 | 主線：問阿德現在需要什麼 |
| K02 想法不等於事實 | 區分事件與解讀，保留尚未確認的可能 | 親手完成想法放大鏡 | 主線：和曉晴聊要不要直接問，由她決定 |
| K03 回到此刻 | 留意當下是可選擇的練習，不必消除情緒 | 親手完成回到這座花園 | 主線：在長椅陪阿德決定今晚的一小步 |
| K04 求助不必獨自承擔 | 遊戲不能診斷；現實支持可依需要尋找 | 完成主線 | 主線後和兩人聊「需要的時候可以找誰」 |
| E01 每個人需要的空間不同 | 支持沒有單一形式，可確認彼此偏好 | 解開謎題「三盆植物」 | 和兩人聊各自喜歡的相處方式 |
| E02 感受不是診斷 | 相似感受可能出現在不同處境，不能據此判定疾病 | 解開謎題「還沒收的三張桌子」 | 和兩人聊不要急著替彼此下結論 |

不適用的卡：提供情境說明與目前目標，不扣分、不消耗。缺少必要卡時，任務目標下方顯示取得來源。

- **背景音樂**：輕柔、可循環，三區各一首或同一首的變奏；只用 CC0 或授權明確允許免費使用的音樂，在素材來源檔記錄曲名、作者、網址與授權；按「開始遊戲」後才播放；設定有音樂開關與音量並記住選擇；進入「回到這座花園」時自動降低音量。

## 10. 工作方式與驗收

- 每一輪先列出預計修改的檔案與做法，經人類確認再動工。
- 每輪完成後實際走完主線，測試兩個謎題、三層提示、文字模式、手機觸控、各階段重新整理後的存檔，附測試紀錄（`docs/測試紀錄.md`，自動化測試 `tests/e2e.cjs`）。
- 不自行購買素材；更新到 GitHub 前先讓人類預覽。
- 正式對外試行前，由合適的心理專業人員審閱對話、疾病敘事、練習與謎題說明及求助文案；審閱前不得宣稱經醫師或心理師核可。
- 建議 8～12 位成年人探索性試玩，觀察玩家能否說明「遊戲不能診斷自己」「不同人的經驗不同」「哪裡可以找支持」，以及是否理解「讀卡」與「在情境中用卡」的差別。
