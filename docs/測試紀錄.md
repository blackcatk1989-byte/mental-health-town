不是截圖展示：每一項都是真的點按鈕、按鍵盤、拖曳搖桿、重新整理頁面，再讀取瀏覽器裡的進度確認結果。

## 還沒驗證、需要人工確認的項目

- **效能（FPS）**：測試機只有軟體繪圖，量到約 4～6 FPS，**不能代表實際裝置**。請在一般電腦與中階手機上實際遊玩，記錄裝置、瀏覽器與 FPS（目標：桌面穩定 30 FPS 以上）。太慢時可在設定改「省電」畫質，或改用文字模式。
- **資源連結是否可用**：測試環境無法連到外部網站，連結內容沿用企劃文件 2026-11-01 的查核結果。正式上線前請逐一點開確認，並更新 `content/resources.json` 的查核日期。理解卡 K01 的來源（WHO 心理急救指南）標示「待核對」。
- **真實手機**：觸控測試是模擬的，請用實機（iOS Safari、Android Chrome）各玩一次，包含橫式畫面。
- **螢幕報讀與鍵盤操作**：按鈕都可以用 Tab 移動、對話選項可按數字鍵，但沒有用螢幕報讀軟體測試。
- **內容審閱**：所有對話、疾病敘事、練習說明與求助文案都是草案，尚未經心理專業審閱（企劃書 7.2 節）。
- **探索性試玩**：企劃書建議 8～12 位成年人試玩，尚未進行。

## 如何重跑

```bash
python -m http.server 8000                 # 另一個終端機
BASE=http://localhost:8000 node tests/e2e.cjs
```

測試會清除這個瀏覽器設定檔裡的遊戲進度（測試用的瀏覽器是獨立的，不會動到你平常的瀏覽器）。
無法連到 jsDelivr 時，加上 `THREE_DIR=<three@0.170.0 套件資料夾>`，測試會改從本機讀取 Three.js。
