### 還沒驗證、需要人工確認

- **真實裝置的流暢度**：測試機只有軟體繪圖，FPS 不具參考性。請用一般電腦與中階手機各玩一次。
- **真實手機**：觸控是模擬的，請用 iOS Safari、Android Chrome 實機試玩（含橫式）。
- **資源連結**：測試環境無法連到外部網站，沿用 v3 的查核結果，正式上線前請逐一點開確認。
- **謎題難度**：線索是否足夠、1～2 分鐘內能否解開，需要真人試玩觀察。
- **內容審閱**：所有對話、練習、謎題與求助文案都是草案，尚未經心理專業審閱。
- 第二輪（Q 版造型、場景完整度、背景音樂）尚未製作。

## 如何重跑

```bash
python -m http.server 8000                 # 另一個終端機
BASE=http://localhost:8000 node tests/e2e.cjs
```

測試會清除測試用瀏覽器裡的遊戲進度（不會動到你平常的瀏覽器）。無法連到 jsDelivr 時，加上 `THREE_DIR=<three@0.170.0 套件資料夾>`。
